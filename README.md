# First HTML & CSS Learning Lab

A hands-on collection of fundamental HTML5 and CSS exercises created during my early web development practice. This repository documents my exploration of core web building blocks: semantic tags, box model, text styling, and CSS selectors.

## Topics Covered

- **HTML Fundamentals**: Document structure, headings, paragraphs, links, and image embeds.
- **CSS Selectors**: Class selectors, ID selectors, and basic element targeting.
- **Box Model**: Margin, padding, border, and outline calculations.
- **Typography**: Web font imports, font weights, line heights, and text decoration.

## File Directory

| File | Focus / Concept |
|------|-----------------|
| `index.html` | Base document layout and introductory markup |
| `class_select.html` | CSS class and ID selection patterns |
| `fonts.html` | Google Fonts integration and typographic styling |
| `padding.html` | Box model spacing and padding behavior |
| `outlline.html` | Border vs. outline visual distinctions |
| `text_style.html` | Colors, alignment, letter-spacing, and line-height |

## How to Run

Simply open any `.html` file directly in any modern browser (Chrome, Firefox, Edge) to view the rendered page.
